DUAL ePORTAL SESSION

Server 與目前瀏覽器各自維持獨立 ePortal session。

Server 使用 .eportal-profile/ 的 Playwright persistent profile。點卡片時， Server 會向 ePortal 取得該系統當下產生的短效 SSO handoff，然後立刻把目前瀏覽器 redirect 到目標系統。Incognito / 訪客模式不需要先持有 ePortal cookie。

此瀏覽器 ePortal 尚未檢查 點登入或任一系統卡片即可檢查。

自動登入偵測使用 NUTC Portal Userscript。 安裝 / 更新 Userscript

Server 背景 ePortal 尚未檢查 供卡片 SSO handoff、背景工作與排程使用。
