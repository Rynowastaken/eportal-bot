DUAL ePORTAL SESSION

Server 與目前瀏覽器各自維持獨立 ePortal session。

Server 使用 .eportal-profile/ 的 Playwright persistent profile，供排程與背景抓取使用。 所有 Dashboard 卡片都可使用 Server 的 .eportal-profile/ 載入資料，因此 Incognito / 訪客模式也能使用。 每個內部頁面仍保留「開啟官方系統」入口；那個官方連結才會使用目前瀏覽器自己的 cookie。

此瀏覽器 ePortal 尚未檢查 點登入或任一系統卡片即可檢查。

自動登入偵測使用 NUTC Portal Userscript。 安裝 / 更新 Userscript

Server 背景 ePortal 尚未檢查 只供背景工作 / 排程，不會登入目前瀏覽器。

所有卡片預設開啟 Server-backed Dashboard view；若要進入真正的官方網站，再從模組頁面點「開啟官方系統」。

Cloudflare Access 保護 Dashboard

Dashboard 本身由 Cloudflare Access 保護；server-side Chromium 只用於獨立 ePortal session 與背景工作。

Session 完全分離

Server cookie 只留在 .eportal-profile/；client cookie 只留在目前瀏覽器。Userscript 不會把 cookie 傳給 server。
